# Android source baseline (v1.2, **not** the final design)

This is the last available native Android project, not a compiled APK.
Its widget layout predates the v3-v10 HTML visual studies. Do not assume these visual studies are implemented here.

Refer to `../AGENTS.md`, `../docs/DESIGN_SPEC_zh.md`, and `../docs/IMPLEMENTATION_PLAN.md` before editing.

Build from this directory with Android SDK 35 / JDK 17 / Gradle 8.9 / AGP 8.7.3. Offline build verification has **not** been completed.
Original historical instructions remain in `README_original_v1_2.md`.
