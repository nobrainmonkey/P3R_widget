# P3R 规划 · Persona 3 Reload 社群日程规划

离线运行的 Android 应用 + 桌面小组件。根据你**现在的存档状态**和想 MAX 的社群，把从今天到 1 月 31 日的**每一个白天和晚上**都排好，并且整份安排前后自洽：每一步对现金、个人能力值（学力/魅力/勇气）、社群 RANK、解锁进度和塔尔塔罗斯次数的影响都会推演下去，后面的安排建立在前面的结果之上。

> 不追求“全局最优”，追求“相对优秀、靠得住”：先满足你选的目标，剩下的时间尽量把其他社群也拉满。

## 下载

到 [Releases](https://github.com/nobrainmonkey/P3R_widget/releases) 下载最新的 `P3R-Planner-<版本>.apk`，在手机上打开安装即可（需要允许“安装未知应用”）。

**关于旧版本（2.0.0 “P3R”）**：新版的包名是 `app.p3r.planner`，会作为一个**新应用**安装，不会覆盖、也不会删除旧版的数据（旧版用的签名证书不在这里，无法原地升级）。

- 旧版「固定攻略」的打勾进度：在旧版里打开固定攻略 → 导出进度，然后在新版「我的 → 逐日攻略」里导入。
- 规划进度：新版第一次打开时，用设置向导把当前存档状态录一遍（日期、现金、三项能力、各社群 RANK），大约一两分钟。

## 怎么用

1. **第一次打开**：选目标社群（「必须」/「想要」），回答“约会时是否带着同阿尔卡那的人格面具”，再照着游戏画面录入日期、现金、个人能力值和社群 RANK。
2. **每天玩的时候**：看「今天」页或桌面小组件的下一步，做完点「完成」。
   - 训练、打工：一下记录。
   - 社群约会：弹出小面板，「已升到 RANK 7」/「没升级」/「其他结果」，点一个就行。
   - 塔尔塔罗斯：填到达的最高层，现金填“现在余额”或“本次增减”其中一个。
3. **没按计划走**：点「做不了 / 改做别的」选原因或实际做的事，后面的安排会自动重排。
4. **很久没记录**：「我的 → 同步现状」，填今天的游戏日期，只改和预计不一样的数值。

所有记录都能撤销（「我的 → 记录历史」）。

## 规划是怎么算的

- 按时间顺序完整推演整个日历，每个时段只做一件事。
- 搜索方法：贪心基础策略 + 前瞻“滚动推演”（rollout）。每个时段比较几个候选，各自往后模拟到年底，选最终结果最好的那个。手机上几秒内算完，算不完也会给出覆盖到 1 月 31 日的完整安排。
- 每份计划生成后都由独立的校验器检查：不重复占用时段、不在锁定日期行动、不超支、不超过进塔上限、RANK 推演一致。
- 看不见的数值（好感点数、能力值点数）只用保守估计，并且和你确认过的状态分开保存：预测永远不会被当成已发生的事实。普通约会 +10 点是估计值（游戏显示 ♪♪），在「规划说明」里写明。

## 数据来源

优先使用从 P3R 游戏文件中提取的数据表（社群点数阈值、加成系数、能力值阈值、假日邀约日期、塔尔塔罗斯区块开放日、官方简体中文名称），其次是 Reload 专用的社群日历和攻略站，并排除 P3/FES/P3P 的旧数据。每条规则都记录了来源和可信度，详见 `rules/build/REPORT.md` 与 `rules/sources/SOURCES.json`。

## 从源码构建

所有构建依赖（JDK 17、Android SDK、Gradle 缓存）都放在项目目录内的 `.toolchain/`，不会安装到系统里。

```bash
scripts/setup_toolchain.sh
```

```bash
scripts/build_release.sh
```

产物在 `dist/`。发布签名密钥放在 `.signing/`（已被 git 忽略，不会上传）；没有密钥时会退回调试签名。

## 目录

| 路径 | 内容 |
|---|---|
| `android/` | Android 工程（`v3/` 为新规划器；`MainActivity`/`PlannerWidget` 为保留的逐日攻略） |
| `rules/build/` | 规则包编译脚本，生成 `android/app/src/main/assets/p3r/p3r_rules.json` |
| `rules/p3r/`, `rules/sources/` | 规则证据与来源快照（不打包进 APK） |
| `docs/DESIGN_v3.md` | v3 设计文档 |
| `docs/analysis/` | 重写前对旧代码、数据、来源和交互的分析报告 |
| `P3R_HANDOFF_PROMPT.md`, `P3R_Planner_Handoff_20261013.zip` | 交接文档与原始交接包 |
