# P3R 规划 · 日程、提示、图鉴与合成

离线运行的 Android 应用 + 桌面小组件。根据你**现在的存档状态**和想 MAX 的社群，把从今天到 1 月 31 日的**每一个白天和晚上**都排好，并且整份安排前后自洽：每一步对现金、个人能力值（学力/魅力/勇气）、社群 RANK、解锁进度和塔尔塔罗斯次数的影响都会推演下去，后面的安排建立在前面的结果之上。

先满足你选的目标，剩下的时间默认「尽量都体验」：先解锁社群、均衡升级，再冲 MAX。

## 下载

下载正式版 [P3R-Planner-3.5.0.apk](https://github.com/nobrainmonkey/P3R_widget/releases/download/v3.5.0/P3R-Planner-3.5.0.apk)，在手机上打开安装即可（需要允许“安装未知应用”）。完整说明和校验文件见 [3.5.0 Release](https://github.com/nobrainmonkey/P3R_widget/releases/tag/v3.5.0)。

**正式版安装**：[3.5.0](docs/RELEASE_NOTES_3.5.0.md) 沿用 3.3.0 签名，可以直接覆盖 3.3.0～3.4.2 并保留进度。3.2.0 及更早版本的更新步骤见[签名与迁移说明](docs/RELEASE_SIGNING.md)。

**从 3.0.x 更新**：3.1.0 去掉了「我的 → 逐日攻略」，更新后就看不到它的打勾进度了。想保留的话，**更新前**先打开逐日攻略，点右上角的菜单按钮打开「设置」，再点「导出进度备份」（这个文件可以导入旧版 2.0.0 “P3R” 的固定攻略）。已经更新了也不要紧：打勾进度并没有被删除，仍然留在手机上；从 3.1.1 起，「我的 → 备份与恢复」里有「旧版逐日攻略」一节，点「导出打勾进度」就能导出同样的文件（手机上没有打过勾的进度时，不会显示这一节）。桌面上的「P3R 逐日攻略」小组件更新后会失效，长按移除即可；「P3R 每日安排」不受影响。

**关于旧版本（2.0.0 “P3R”）**：新版的包名是 `app.p3r.planner`，会作为一个**新应用**安装，不会覆盖、也不会删除旧版的数据（旧版用的签名证书不在这里，无法原地升级）。

- 旧版「固定攻略」和它的打勾进度留在旧版里：新版只做安排，不含固定攻略，也不导入那份进度。
- 存档进度：新版第一次打开时，用设置向导把当前存档状态录一遍（日期、现金、三项能力、各社群 RANK），大约一两分钟。

## 怎么用

底部五个页面是「今天 / 日程 / 社群 / 提示 / 我的」。桌面小组件按 **5×2** 大小设计，最小使用 **4×2**；实际格距随手机桌面而异。

1. **第一次打开**：选目标社群（「必须」/「想要」），回答「见面时通常带着同阿尔卡那的人格面具吗？」（基本都带 / 只给目标社群带 / 不带·不一定），再照着游戏画面录入日期、现金、个人能力值和社群 RANK。中途存档还会问失踪者是否已经救出。
2. **每天玩的时候**：看「今天」页或桌面小组件的下一步，做完点「完成」。
   - 训练、打工：点一下就记好。
   - 宿舍活动：完成后记录项目次数和相关社群好感；同一项目做满 3 次解锁队友特性，两种项目各做满 3 次强化特性。在「社群」页选定特性目标后，安排还会为该目标预留活动机会。
   - 和社群的人见面：弹出小面板，「升到 RANK 7 了」/「没升级」/「没见到」，点一个就行。需要带人格面具时会提醒你带哪个阿尔卡那。
   - 塔尔塔罗斯：填到达的最高层，现金填「出塔后余额」或「这次多了多少」其中一个。
   - 顺便要做的事（比如给田中社长付款）会写在同一项里，不会消耗时间。
   - 见面时该选哪句：小组件上直接写「答：…」，不用点进去看；课堂提问和考试的答案也会写在当天的卡片上。
   - 对话短句按提问顺序用「/」分开，「或」表示同一问的可选回答；点开详情可看包含「任意」在内的完整顺序和路线条件。19 个手动社群的 R2–R10 均有提示，友情、恋人直接按你的设置显示；中途存档走过不同分支时，详情列出对应答法。优先沿用有来源的简中选项，找不到中文的部分按外语资料译意。
   - **今天别错过**：不会消耗时间但值得做的事会在当天提醒——课堂提问和考试的答案、上课犯困时闭不闭眼、去保健室、电视购物、伊莉莎白的新委托和截止日期、失踪者、黄昏的碎片、新开的店。
   - 点开委托提醒可看取物地点、前置委托、多日准备和截止注意事项；需要消耗晚上的挑战会单独说明。
   - **提示**：按本次塔尔塔罗斯楼层开放到下次开放前一天查看当期事项，也可搜索全年攻略。包含全部 101 条委托、97 条战斗、社群答案和课堂／考试答案；支持编号、名称和楼层搜索。点「筛选」可按委托、战斗、社群、课堂及救援、解锁等条目标签查找。社群答案按你选的朋友／恋人路线显示，点详情看完整顺序。
3. **没照安排走**：点「做不了 / 改做别的」选原因或实际做的事，后面的安排会自动重新安排。
4. **很久没记录**：「我的 → 同步现状」，填今天的游戏日期，只改和预计不一样的数值。宿舍活动可补填每个项目实际做过的次数（0–3，更多也填 3），不会重复补发三维；没记录的先按 0 次安排。
5. **想从头再排一遍**：「我的 → 从头重新安排」，重新读取进度和规划设置，从头排到 1月31日。普通计算给 8 秒预算；点「深度计算」给 30 秒预算，比较更多行动和策略。深度计算会先校验现有安排，再按当前目标和安排风格参与比较。
6. **规划设置**：可以选「尽量都体验」（默认）或「尽量多 MAX」。可开启「深度修改」，设置会保留；以后每次记录进度或修改规划设置，自动重排给 12 秒预算。
7. **可选目标**：在「社群」页为 9 名队友分别选特性「不追求 / 解锁 / 强化」，默认不追求；选的时候可核对两种宿舍活动实际做过几次。「解锁」只争取任一种活动满 3 次，「强化」才争取两种各满 3 次；已经达成的目标不再为特性安排。没有宿舍特性的社群不会显示这个选项。也可勾选想看的羁绊剧情（顺平、真田、虎狼丸、天田、荒垣）；11 月后会用「结缘网站的字条」把多出来的晚上换成社群好感。
8. **想安排园艺**：在「同步现状 → 宿舍活动」开启「允许安排园艺」，并提前种好作物。园艺默认关闭，种苗费用和作物状态需要自己准备、确认。
9. **查面具与合成**：在「提示」或「我的」打开「图鉴与合成」。可搜中英文名称和技能，按塔罗牌、等级筛选、排序，收藏常用面具。点开面具可看相性、技能和合成配方，配方里的材料可以继续点开；「合成」里也能直接选两个材料。先勾选已购买的面具 DLC，结果会按你的组合变化。收藏和 DLC 会随备份保存。

所有记录都能撤销（「我的 → 记录历史」），之后改目标或人格面具设置也不会改写已经确认过的记录。

## 安排是怎么算的

- 按时间顺序完整推演整个日历，每个时段只做一件事；每一步的结果（钱、个人能力值、RANK、解锁进度、塔尔塔罗斯次数）都会带到后面。
- 需要付钱解锁的社群（比如恶魔社群的三次付款）：交完钱手上至少还留 2,500 日元；快到交钱的时候，花钱提升能力和买结缘网站的字条都不会动用要交的钱。只有晚交会赶不上升级目标时，才会留得比这少。
- 三维训练和解锁资金跟随「必须／想要」目标。多个「必须」需要的前置会一起准备，按实际开放日期、缺口和剩余训练机会决定先后；不会因为目标排在后面，就等前一个 MAX 才开始练它需要的属性。
- 校内社群共用的上学日会单独计算竞争：能在暑假、假期推进的校外社群，优先使用那些日期。11 月后的结缘字条按能省下多少白天见面计分，也保留多张累积补好感的价值；有可用的后续见面才安排。
- 进塔会考虑所有失踪者的出现日期和期限，尽量等同一期的人到齐后一起救；可行时留出截止前一天的余量，并遵守每区块的探索次数设置。
- 会根据三维和已了解的菜单选择限定餐：定食若津的水产全席套餐（魅力 Lv.3，学力 +4）和叶隐的限定餐（勇气 Lv.3，魅力 +4）。菜单尚未了解时先安排一次普通餐，日期和现金条件满足后再使用限定餐。
- 考前集体学习按 14 个限定晚上参加，免费提升学力。宿舍活动按有用的三维和相关社群好感参与安排；选了队友特性目标后，才额外考虑达成解锁或强化的价值，机会快用完时提高优先级。目标达成后，不会再为该特性安排；仍有三维收益的项目可以继续作为免费训练。它们不花活动费，但会占用晚上。救援期限和按顺序排列的「必须／想要」社群目标仍优先；选定特性会和其余社群、训练及打工竞争，可能减少其余社群的见面机会。由加莉、风花、美鹤和埃癸斯的两项宿舍活动可补对应已解锁社群的好感，三次以后仍有效，缺口已满时停止为好感安排。
- 搜索方法：贪心基础策略 + 前瞻“滚动推演”（rollout）。每个时段比较几个候选，各自往后模拟到 1 月 31 日，选最终结果最好的那个；白天优先留给社群，能在晚上练的个人能力值不占白天，打工只在需要用钱时安排。
- 在后台计算：普通重排 4 秒，补算和普通从头重排 8 秒；开启「深度修改」后，记录或修改设置触发的自动重排给 12 秒；手动「深度计算」给 30 秒。12 秒修改完成后不再追加 8 秒补算。计算期间仍可记录进度。
- 12 秒和 30 秒计算都会先执行普通搜索并保留结果，再用剩余时间扩大行动和策略搜索；普通搜索包含在总预算内。
- **尽量都体验（默认）**：不是目标的社群，每升一级的价值递减——解锁一个新社群最值，已经很高的社群再升一级没那么值，所以安排会先把所有社群都解锁、都往上提；MAX 仍然有额外的价值。安排时还会同时算一份「尽量多 MAX」的安排来对比，保证「尽量都体验」不会在解锁数、RANK 5 以上的社群数和 RANK 合计上全面输给它。
- 见面和最终目标比较仍严格按顺序优先；加入后面的目标时，搜索也会单独检查前面目标的策略，保留兼顾前面目标的路线。属性和资金准备按目标档位及实际日期共同安排。不同存档、目标和安排风格的完整模拟结果见 [`docs/PLAN_METRICS.md`](docs/PLAN_METRICS.md)。
- 每份安排生成后都由独立的校验器检查：不重复占用时段、不在剧情日行动、不超支、不超过塔尔塔罗斯次数上限、RANK 推演一致。
- 重排时会从当前进度校验并回放旧安排的剩余部分，仍可执行的路线按当前目标和安排风格参与比较，保留适用的深度计算成果；实际进度有偏差时，剔除不合法的后续并按现状重排。
- 看不见的数值（好感点数、能力值点数）只用保守估计，并且和你确认过的进度分开保存：预计永远不会被当成已发生的事实。普通见面 +10 点是估计值（游戏里约显示 ♪♪），在「规划说明」里写明。

## 数据来源

优先使用从 P3R 游戏文件中提取的数据表（社群点数阈值、加成系数、能力值阈值、休息日邀约日期、塔尔塔罗斯区块开放日、官方简体中文名称），其次是 Reload 专用的社群日历和攻略站，并排除 P3/FES/P3P 的旧数据。每条规则都记录了来源和可信度，详见 `rules/build/REPORT.md` 与 `rules/sources/SOURCES.json`。

图鉴与合成参考 [aqiu384 / Megaten Database](https://github.com/aqiu384/megaten-database) 和 [Megaten Fusion Tools](https://github.com/aqiu384/megaten-fusion-tool)；后者代码使用 Unlicense。面具和技能优先采用游戏官方简中、英文名称，不收录图片。

## 从源码构建

所有构建依赖（JDK 17、Android SDK、Gradle 缓存）都放在项目目录内的 `.toolchain/`，不会安装到系统里。

```bash
scripts/setup_toolchain.sh
```

```bash
scripts/build_release.sh
```

产物在 `dist/`。

验证构建不依赖项目目录以外的任何东西（空环境、空 HOME、Gradle 离线模式，并检查 ~/.gradle、~/.m2、~/.android 没有新文件）：

```bash
scripts/verify_selfcontained.sh
```
发布签名密钥放在 `.signing/`（已被 git 忽略，不会上传）；正式发布脚本在缺少签名配置时会停止，私钥的备份与 CI 配置见[签名说明](docs/RELEASE_SIGNING.md)。
