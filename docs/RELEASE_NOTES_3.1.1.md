# P3R 规划 3.1.1

3.1.0 之后的补充和修正。

## 新增

- **导出旧逐日攻略的打勾进度**：从 3.0.x 更新过来、没来得及导出的也不要紧——打勾进度一直留在手机上。现在可以在「我的 → 备份与恢复 → 旧版逐日攻略」里点「导出打勾进度」，导出的文件和以前逐日攻略里「导出进度备份」的完全一样，可以导入旧版 2.0.0「P3R」的固定攻略。手机上没有打过勾的进度时，不会显示这一节。导出只读取，不会改动或删除这些记录。

## 修正

- **课堂提问答案补齐**：3.1.0 暂时没有显示的 12月7日、12月9日、12月11日、1月18日 的课堂提问答案，现在找到了《女神异闻录3 Reload》简体中文攻略的原文（游民星空转载的全社群 MAX 日程攻略，以及 BWIKI），两份来源一致，选项位置也和 Reload 的游戏数据对得上。全年 36 次课堂提问的答案都会提醒。
- **失踪者期限**：期限当天的晚上去塔尔塔罗斯仍然能救出——按 Reload 的游戏数据（失踪者表的起止日期）和实际通关记录核对过。提醒的文字不再写「期限当天还算不算没核对过」。
- **小组件**：卡片比较小时，见面的参考回答和当天的课堂提问、考试答案现在都会显示（放不下时课堂答案会排到标题旁边），不会再丢掉其中一个；选项不会被「…」截断。
- 「预计可能升级」的灰色答案文字对比度更高，在浅色小组件上更好读。
