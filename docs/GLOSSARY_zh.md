# 用语表（所有界面、小组件、安排文字、规则包统一遵守）

依据：官方简中（游戏数据表、Steam 成就文本与商店页）＞ 原中文攻略 `rules/sources/cn_guides/data.json` 的写法 ＞ 自然口语。
目标：玩家一眼看懂，不出现工程术语、英文、内部编号。

| 概念 | 统一写法 | 不要用 |
|---|---|---|
| Social Link | 社群；「皇帝社群」「教皇社群」 | 社交链接、羁绊（羁绊另指羁绊剧情） |
| 社群等级 | RANK 6、升到 RANK 7、RANK 6 → 7 | 等级、级别（正文可偶用“级”） |
| 满级 | MAX；「升到 MAX」「已经 MAX」「预计 11月20日 升到 MAX」 | 练满、满级、MAX 当动词 |
| 建立社群 | **解锁**；「完成后恶魔社群就解锁了」「解锁条件」「解锁前的准备（第 1 步，共 3 步）」「未解锁」 | 开启、建立、正式开始 |
| 和社群对象一起度过放学后/白天 | **见面**；「这次见面能升到 RANK 7」「见面（预计不升级）」 | 约会（只用于恋爱，如「平安夜约会」）、会面、加深关系、普通会面 |
| 星期日/节假日的出游邀请 | **休息日邀约**（官方成就文本「休息日的出游邀请短信」）；「休息日邀约 · RANK 6 → 7」「对方发来了休息日邀约，赴约也算一次见面」 | 假日邀约、节日邀约 |
| 平安夜赴约 | **平安夜约会**（剧情占用的原因）；「选了赴约的对象，白天和晚上就都留给平安夜约会」 | 圣诞约会、平安夜邀约占用 |
| Protagonist | **主角**（官方商店页写法「作为主角的少年」）；「主角的能力」 | 主人公、男主 |
| 计划表 | **安排**（名词）、**重新安排**（动词）；规划只用于应用名「P3R 规划」和菜单「规划设置」「规划说明」 | 计划、方案、规划结果、覆盖至、有效安排 |
| 个人能力值 | 学力 / 魅力 / 勇气；等级写 Lv.1–Lv.5，第 6 级写 **MAX**（攻略写法「勇气MAX」） | 社交属性、属性、Lv.6 |
| 塔 | 标题「探索塔尔塔罗斯」；副标题「世俗之庭 台伯勒（2–22F）· 本区块第 1 次」或「… · 救出舞子」 | 爬塔、进塔（口语短标签除外） |
| 失踪者 | 失踪者；「救出北村文吉」 | |
| 失踪者的期限（期限当天晚上还能救） | 「期限 10月3日」「最晚要在10月3日晚上救出」「今天是救出北村文吉的最后期限，今晚去塔尔塔罗斯还来得及」「7月6日当天或更早救出」 | 「10月3日前救出」（读起来像不含当天）、「最好提前去」 |
| 时段 | 白天 / 放学后（上学日的白天）/ 晚上 | 下午、深夜、时段编号 |
| 剧情占用 | 标题用原因（满月作战、期末考试、修学旅行…）；副标题「这段时间不能自由行动」 | 锁定、不可用 |
| 空闲时段 | 自由活动 | 空闲、FREE、等待 |
| 钱 | 现金；「2,500 日元」（千位分隔）；塔：「出塔后余额」｜「这次多了多少」 | 元、円、余额变化量、净值 |
| 打工 | 打工；「在夏卡尔咖啡店打工 · 至少 2,500 日元」 | |
| 人格面具 | 人格面具；同阿尔卡那 | Persona |
| 人格面具加成 | 「见面时带着同阿尔卡那的人格面具，点数 ×1.51」；提示「记得带上「皇帝」阿尔卡那的人格面具」 | |
| 目标档位 | 未选 / 想要 / 必须 | — 、优先级数字 |
| 玩家进度 | 进度；「同步现状」「修改进度」 | 状态、基线、快照、检查点 |
| 结果录入 | 完成、没升级、升到 RANK 7 了、没去成、做不了、改做别的… | 提交、确认实际结果 |
| 估计 | 「预计」；说明里写「估计值」 | 估算模型、候选、规则包 |
| 结缘网站的字条 | 「在放纵俱乐部买结缘网站的字条，回宿舍用公用电脑给 XX 加好感」 | 交友网站、留言 |
| Link Episodes | 羁绊剧情（攻略写法）；「羁绊剧情 · 伊织顺平（第 2 话）」 | 牵绊事件、Link Episode |
| 塔尔塔罗斯区块 | 区块 | 阶段、层段 |
| 完整重新安排（不参考现在的安排） | **从头重新安排**（「我的 → 安排」和「规划设置」底部的入口）；「正在从头重新安排…」「从头重新安排好了：…」；不知道原来的安排时只说「从头重新安排好了，一直排到1月31日」；没找到更好的：「重新算过了，没找到更好的，现在的安排不变」；重新安排出错、原来的安排还在：「生成安排时出了问题，现在的安排先不变」 | 「上一版」「这一版」（指安排时） |
| 安排方式（规划设置最上面的卡片） | **安排风格**：尽量都体验 / 尽量多 MAX | |
| 先解锁、先往上提每个社群（默认） | **尽量都体验**；「先把每个社群都解锁、都往上提，再冲 MAX；时间不够时更均衡。」 | 广度优先 |
| 集中冲 MAX | **尽量多 MAX**；「集中时间把尽量多的社群升到 MAX。」 | |
| 当日提醒（不消耗时间的小事） | 今天页的区块 **今天别错过**；日程详情的小节 **当天提醒**；日程行「提醒：课堂提问 · 电视购物」；应用里的提醒行由标签说明种类，行文不再重复（「课堂提问｜选「马」（第 2 项）」）；小组件提醒行有多条时「 · 共 2 条」；规划说明里写【当天提醒】 | 【当日提醒】（对玩家）、「（共 N 条）」 |
| 课堂上被点名回答 | **课堂提问**；「课堂提问：选「马」（第 2 项）」，小组件「课堂：马（第 2 项）」 | 上课问答 |
| 考试答题 | **考试**；「考试：选「五月病」」，小组件「考试：五月病」 | |
| 上课打瞌睡 | **上课犯困**；「上课犯困时别闭眼：学力 +2」「上课犯困时闭上眼：勇气 +2」 | |
| 学校的保健室 | **保健室**；「放学后先去保健室：勇气 +2，不会消耗时间」（应用里的提醒行不再另写「勇气 +2」） | 医务室 |
| 在房间看电视买东西 | **电视购物**；「电视购物：玫瑰花束、高级巧克力 ×2，2,980 日元」 | |
| Elizabeth 的委托 | **伊莉莎白的第 N 号委托**；「伊莉莎白有新的委托」「伊莉莎白的第 12、13 号委托 6月6日截止」「修学旅行：…，伊莉莎白的第 96 号委托要用」 | 「伊莉莎白第 N 号委托」（少「的」）、只写「第 N 号委托」不提伊莉莎白 |
| 收集品 | **黄昏的碎片**（官方成就文本）；「今天城里能捡到黄昏的碎片（14 处）」 | 黄昏碎片 |
| 不需要时段的事 | **不会消耗时间**；「接委托和交东西都不会消耗时间」 | 不占用时段、不占时间 |
| 对话选项 | 应用里写 **参考回答：**…；小组件写 **答：**…（「答：A / B · 别选表白」「答：怎么回答都可以」；课堂、考试的答案放得下就接在后面「答：好的 · 课堂：变为零」，不然放在标题右边；放不下时「或者」连着的两个说法只写第一个，再不行「答：A 等 3 项」，最矮的卡片上连第一项都放不下时「答：共 2 项，点开看看」） | 小组件上的「参考回答：」、选项里的「…」 |
| 不一定升级时的对话选项 | **要是升级了，答：**…（小组件放不下时「升级时答：」） | |
| 3.0.x 逐日攻略留在手机上的勾选 | **打勾进度**；「备份与恢复」里的小节「旧版逐日攻略」、入口「导出旧逐日攻略的打勾进度」「3.0.x 逐日攻略里打过勾的 12 项还在手机上，导出后可以在旧版 2.0.0「P3R」里导入」「打勾进度已导出。」；2.0.0 那边叫「固定攻略」 | 打卡进度（只留在导出文件名「P3R_打卡进度.json」里，沿用旧页面的文件名）、勾选记录、完成记录 |

语气：短句，像朋友提醒；能用问句就用问句（「升到 RANK 7 了吗？」）；数字后加单位；不要括号套括号。
