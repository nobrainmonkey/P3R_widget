# P3R 规划 3.1.0

这一版的重点是两件事：让安排更像一个想把游戏内容尽量都体验到的玩家会做的选择，以及把玩的时候需要知道的东西直接放到眼前。

## 新功能

- **安排风格「尽量都体验」（默认）**：不是你目标的社群，每升一级的价值递减——解锁一个新社群最值，已经很高的社群再升一级没那么值。所以安排会先把每个社群都解锁、都往上提，再冲 MAX，而不是只冲几个 MAX、不管其余社群。
  - 你选的「必须」「想要」目标照旧严格按顺序优先。
  - 每次都会同时算一份「尽量多 MAX」的安排来对比：「尽量都体验」在解锁的社群数、升到 RANK 5 以上的社群数和 RANK 合计上，不会全面输给它。
  - 想集中冲 MAX 的话，可以在「规划设置 → 安排风格」里换成「尽量多 MAX」。
  - 新建的进度默认勾选全部羁绊剧情；已经存好的设置不会被改动。
- **今天别错过**：不会消耗时间、但值得做的事，会在当天提醒你。「今天」页、日程和当天的详情里都有，桌面小组件上也会显示最要紧的一条。
  - 课堂提问和考试的答案；
  - 上课犯困时闭不闭眼，以及什么时候去保健室（勇气 +2）；
  - 电视购物的新商品和价格；
  - 伊莉莎白的新委托和截止日期；
  - 失踪者和救援期限；
  - 黄昏的碎片；
  - 新开的店。
  - 答案取自 3DM 的《女神异闻录3 Reload》简体中文攻略原文，并和 Reload 的游戏数据、日历逐条核对过日期和选项位置。旧攻略里有 9 处答案照搬了英文版的说法，和简中游戏里的选项对不上（比如 5月19日应为「五月病」），这次全部改正。没有可靠简中原文的 4 天课堂提问暂不显示。
- **小组件上直接显示该选哪句**：见面时写「答：A / B」，不用点进去看。
  - 预计这次不一定升级时，写成「要是升级了，答：…」。
  - 走朋友路线时会提醒别选表白的回答。
  - 小尺寸时用更短的写法，选项不会被截断；实在放不下时写「等 N 项」，点开就能看全。
- **从头重新安排**：「我的 → 从头重新安排」会重新读取你记下的进度和规划设置，不参考现在的安排，从头排到 1月31日。比平时多算几秒；算完会告诉你哪里变了，或者「安排没有变化」。

## 数据

- 埃癸斯（永劫）只在周一、三、五、六放学后见面：多份 Reload 攻略都这样写，按「来源不一致时取更严格的说法」的规则修正。
- 数据来源经过独立复核：没有任何规则用到 P3、FES 或 P3P 的旧数据。

## 外观

- 正文里的词、人名和地点不会被拆到两行；一行不会只剩一个字、「吗？」或「·」「/」。
- 「社群」页、塔尔塔罗斯记录面板、「今天」页按钮、读取失败提示等处的细节都做了打磨。
- 桌面小组件的改进：
  - 已经在显示当前这一项时，「当前」会变暗。
  - 出错、全部完成、剧情日等状态，只显示一个能点的按钮。
  - 小尺寸和大字号下，能力值、人名、地点都不会被「…」截断。
  - 卡片在最小尺寸也总会写明是谁或做什么。
  - Android 8–11 上也是圆角。

## 从 3.0.x 更新

- 直接覆盖安装即可（同一个包名 `app.p3r.planner`、同一个签名证书）。记录和设置都会保留，打开后会自动重新安排一次。
- 3.1.0 去掉了「我的 → 逐日攻略」，更新后就看不到它的打勾进度了。想保留的话，**更新前**先打开逐日攻略，点右上角的菜单按钮打开「设置」，再点「导出进度备份」；这个文件可以导入旧版 2.0.0「P3R」的固定攻略。（3.1.0 发布后补充：已经更新了也不要紧，打勾进度并没有被删除，仍然留在手机上；3.1.0 之后的更新会在「我的 → 备份与恢复」里加上导出。）
- 如果桌面上还有「P3R 逐日攻略」小组件，更新后它会失效，长按把它移除就好；「P3R 每日安排」不受影响。
- 当天提醒里的能力值加成和电视购物花的钱不在安排的预计里，做了以后去「同步现状」更新一下，安排会更准。
