# P3R 规划 3.4.0

版本码 38。

## 攻略随时查

「提示」新增全局搜索；保留本期／全部范围，分类和救援、解锁等条目标签收进一个「筛选」按钮。

- 社群：171 个 R2–R10 场景，按朋友／恋人路线显示短答，详情有完整顺序和分支。
- 课堂与考试：全年 53 条答案。
- 委托：第 1–101 号，每条都有名称、做法、前置、期限和奖励。可搜「委托75」「#75」、名称或道具。
- 战斗：97 条攻略，覆盖守关首领、蒙纳多门与通道、满月及剧情战、最终战和特殊挑战。阵容卡配九属性抗性表，可按楼层或名称搜索；固定通道按楼层和连续战序排列。

不必照日程走，也能直接查攻略。中文优先沿用官方简中，缺少的译意补齐。

## 安排更合理

- 三维按社群开放时间和剩余日期安排，为后续免费宿舍活动、集体学习留出缺口。
- 补入暑期补习每天学力 +3，六天共 +18。
- 有用的免费活动和选定的队友特性目标优先参与安排；必须／想要社群仍按你的顺序处理。
- 女性队友宿舍活动计入对应社群好感，做满三次后仍能补好感缺口；旧记录不补发收益。
- 魅力 MAX 按实际能减少的见面次数计分，太阳、恶魔等不会省次数的社群不再抬高训练价值。
- 对照全收集攻略，恢复永劫 5 天、女皇 3 天被误删的见面机会。
- 打工只为近期实际支出筹钱，三维已满、钱也够时不再反复去咖啡店。
- 休息日短信改为「收到短信才选」的手动赴约，不再当作确定的升级机会。
- 考试、旅行等剧情日期逐日显示原因，点「剧情已过，继续」进入下一天。
- 提示文案精简为答案、做法、条件和期限。
- 二级弹窗统一标题、底板和选中态。
