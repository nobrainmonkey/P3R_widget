# 社群回答新增与缩写预览（待确认）

对应规则包：`3.2.0|2d37701105fe`。**这份文件是文案提案，尚未加入代码、规则或APK；按用户要求，获得确认后才实施。**

## 显示方式

- 沿用现有风格：应用写“参考回答：”，小组件短卡写“答：”。下面主要展示普通短卡文案；详情保留完整原文、问答顺序及必要条件。
- 保留玩家能直接对上选项的中文原话，删攻略说明和意义未核实的括号数字。不会缩成“鼓励她”“安慰他”“让对方开心”。
- `/` 表示依次出现的不同问题；“或”表示同一道题的备选回答。相同回答出现在不同问题时仍保留，不按文字去重。
- 混合问答里的“任意”按现有短版做法省略；有必要定位时说“最后一问”。全段确实随意时才写“怎么回答都可以”。
- 有恋爱分支就分开写；恋爱资格前置只说“想保留恋爱分支”，不冒充已经确定关系。
- 空间更窄时沿用已有排版缩短方式，不在选项中间截出“…”；战车R8的“……”是原选项，另注保持沉默。
