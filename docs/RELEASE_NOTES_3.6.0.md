# P3R 规划 3.6.0

界面和操作整体重做，更接近《女神异闻录3 Reload》的菜单：亮蓝的「心之海」背景、斜切面板、大号斜体数字、白色主按钮（和桌面小组件的「完成」一样）、滑动的选中条、每页的英文标题字和水印。安排、记录、备份和桌面小组件都没有变。

- **今天**：日期牌后面有 WEEKDAY / WEEKEND 字样，周日和节假日为红色。现金和个人能力值合成一条，点一下就能修改进度。下一步的卡片和小组件一样：社群升级时显示目标 RANK 的大号数字，回答只写「回答：…」，只保留期限、最后机会、只在某些日子出现这类要紧的理由，别的安排解释都去掉了。记下社群升级时会出现「RANK UP!!」。
- **日程**：按天排成时间线，不再一天一个框；今天高亮，昨天变暗，同一天的剧情占用合成「全天」一行；「回到今天」只在看不到今天时出现。点开某天：和今天页一样的「做不了… / 完成」，不再有「为什么这样安排」「安排依据」。
- **记录历史**：按游戏日期分组；改过的记录标「已修改」，被替换的原记录标「原来记的」；在别处改了记录，打开着的记录历史会自己更新。
- **从头重新安排**：只剩一个选项，最多半分钟，期间可以照常记录。
- **社群**：分成「社群」「羁绊剧情」「队友特性」。社群是塔罗牌样式的卡片，「必须」是白底；点卡片打开社群详情，在里面改目标和回答路线。目标顺序单独调整。
- **提示**：标签一点就筛选（社群、课堂 · 考试、委托、战斗、其他）；「全部」先显示目录；本期的委托合成一组；社群对话直接显示下一次 RANK 的回答。
- **全书**（原「图鉴」）：官方叫法「人格面具全书」「合体」「特殊合体」，属性改用游戏里的名称（火焰、神圣、暗黑、恢复）。列表、面具资料、合体和合体篮（原「合成篮」）都重新排版；加入合体篮后留在原页面。合体篮的算法不变。
- **我的**：游戏进度和「同步现状」放在最上面，设置项去掉了说明文字。「其余社群也尽量提升」移到「规划设置 → 其他设置」。
- **设置向导**：先问游戏进度，最后选目标；同步时选「基本照着玩了」可以直接核对；「修改进度」可以只改一项。
- **记录结果**：只问发生了什么，不再重复见面前的提示；选项更少。
- 全部文字去掉了道歉、含糊和解释算法的句子，出错时直接给「重试」。
- 修正：从桌面小组件点开今天或日程时，不再停在上次没关的子页面上；连点两下不会替还没看到的问题作答；修改打工记录时现金不再丢失。

沿用 3.3.0 起的签名，可直接覆盖 3.3.0～3.5.1 并保留进度。
