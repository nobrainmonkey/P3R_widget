# P3R 规划 3.7.0

- **目标优先级简化**：去除社群目标内部的先后次序。「必须」和「想要」两档严格分层，同档内社群完全平等，由排程算法自动寻找最优推进方案，不再需要手动调整顺序。
- **校历与暑假压力感知**：排程算法全面考虑游戏中期暑假（7月下旬至8月）与考试前夕学校社团关闭的天然限制，在学期中优先推进校内社团，将假日、周日及暑假合理留给校外社团与五维/夜间活动。
- **全量 UI/UX 语言审计与润色**：
  - 全面消除机器腔、翻译腔与内部缩写（如「营业」「时段」「已记」「社3/宿2」等）。
  - 清除全部道歉、公文腔与含糊词（「暂时」「可能」「不一定」「请稍后再试」等）。
  - 严格规范官方中文专有名词（如「火焰/神圣/暗黑」属性、「阿尔卡那」、「猎杀者」、「染血的纽扣」、「平安夜约会」等）。
  - 18 位失踪者统一使用官方简中译名（如北村文吉、舞子等）。
  - 桌面小组件全面精简，去除「目标」「有空就练练」等内部求解理由，仅在关键节点展示必要提醒。

沿用 3.3.0 起的签名，可直接覆盖 3.3.0～3.6.3 并保留进度。
