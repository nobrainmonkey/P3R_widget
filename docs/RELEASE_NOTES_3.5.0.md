# P3R 规划 3.5.0

- 新增「图鉴与合成」：收录本体 173 个面具和 21 个 DLC 面具，提供官方简中、英文名称、属性相性、能力值、初始技能和升级技能。
- 图鉴支持中英文搜索、技能搜索、收藏，以及塔罗牌和等级筛选、排序。入口在「提示」和「我的」。
- 可查看一个面具的合成配方，也可选两个材料查看合成结果；特殊合成单独列出，材料和结果都能点开图鉴。
- 可选择已购买的三个面具 DLC 组合，合成结果随之调整。收藏和 DLC 选择会一起备份。
- 进塔救援直接标出楼层，详情按楼层列出每名失踪者；提示页也能搜索楼层。
- 解锁步骤与前置社群保留一个候选名额，目标优先级会沿未完成的多层前置传递，达到所需等级后停止。
- 更新后自动重算未来安排，保留已记录的游戏进度。

图鉴数据与合成规则参考并致谢 [aqiu384 / Megaten Database](https://github.com/aqiu384/megaten-database) 和 [Fusion Tools](https://github.com/aqiu384/megaten-fusion-tool)。

沿用 3.3.0 起的签名，可直接覆盖 3.3.0～3.4.2。
