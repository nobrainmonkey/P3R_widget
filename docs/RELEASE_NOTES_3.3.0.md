# P3R 规划 3.3.0

代码更新说明；本轮尚未发布 3.3.0 正式安装包。

## 新增「提示」页面

- 底部现在是「今天 / 日程 / 社群 / 提示 / 我的」。在「提示」可集中查看整期已收录的委托做法、截止日期、提前准备、全部课堂与考试答案、社群解锁、羁绊剧情窗口、限定学习、宿舍活动、电视购物和失踪者等内容。
- 一期从本次塔尔塔罗斯楼层开放，到下次开放前一天；最后一期到 1月31日。与本期办理窗口重叠的跨期委托继续保留。
- 无期限的外出邀请、第 75 号委托等条件提示也会跨期保留，不会因为攻略里的参考日期过去就消失。
- 社群解锁会说明最早开放日期、三维或前置社群要求和办理步骤；羁绊剧情会列出本期能看的具体日期、整段窗口的截止日期、前一话要求、触发方法和已有收益说明。不受本次目标或勾选的剧情限制，也不会把「到了开放日期」当成「已经满足条件」。
- 补上规则中已有的放榜、假日、开放日期等日历说明；连续同原因的剧情占用会合并显示，包含考试中不用手选答案的日子、暑期补习、旅行和满月作战。这里只展示已有事实，不额外推算收益。
- 按「当前要留意 / 接下来别错过 / 本期已过日期」排列。已经过去的日期也能回看，日期已过不代表已经完成；条件提示仍须满足实际条件，点卡片可看完整详情。
- 内容直接来自规则，不要求当天安排里刚好带有提醒；没有当前安排或正在重新安排时也能查。浏览提示不会记录完成、扣钱或自动增加属性。

## 免费学习和宿舍活动参与安排

- 加入 14 个考前集体学习的限定晚上，普通学习预计学力 +4，全员学习保守按 +5。免费，但会消耗晚上；学力已满时不会为练学力继续安排。
- 加入 9 名队友、18 种宿舍活动。看书、看 DVD 等同时考虑三维收益和特性进度；做饭、泡茶、煮咖啡、梳毛等即使不加三维，也会为队友特性安排。
- 同一种活动做满 3 次解锁特性，两种活动各做满 3 次强化特性。三维已满仍会争取未完成的特性；可用日期快用完时会提高优先级。
- 已做满 3 次且没有剩余三维收益的项目，不会为了特性重复刷。失踪者救援期限和你选的社群目标仍然优先。

## 补填实际进度

- 「我的 → 同步现状」增加「宿舍活动」：每个项目填实际做过几次，超过 3 次填 3。补填次数不会重复增加三维。
- 更新前没有记录的项目先按 0 次安排；补填后会重新计算。已记录的活动次数随进度备份、恢复，也能撤销。
- 卡片显示这个项目的预计次数，以及是否预计解锁、强化特性。预计不等于已经完成，仍以你实际记录的结果为准。

## 园艺需要提前种菜

- 园艺默认不安排。在「同步现状 → 宿舍活动」开启「允许安排园艺（我会提前种好作物）」后，才会考虑和队友种菜。
- 活动本身不另收费，但种苗要自己准备；作物状态、种苗费用和收获道具不在现金、物品推演里。虎狼丸散步也不会算成梳毛次数。
- 宿舍活动可能带来的社群好感暂不计入推演；宿舍活动、集体学习与羁绊剧情分别计算进度。

## 小组件大小

- 按 **5×2** 大小设计，最小使用 **4×2**；实际格距随手机桌面而异。
- 调整字体测量，使中文行高和标题自动字号与实际显示一致；缩短少数友情路线的卡片注释，完整回答与条件仍可在详情查看。

## 更新安装

安排会把一部分晚上留给队友特性，因此非目标社群的 MAX 数量不保证不变。例如不带人格面具的新游戏基准从 22 个 MAX 变为 21 个；社群目标、救援期限和现金检查仍保留。完整对比见[安排质量](PLAN_METRICS.md)。

后续正式发布应沿用 **3.2.0 的正式签名**，才能让已安装 3.2.0 的用户直接覆盖更新。当前工作环境尚未恢复这份签名配置，因此本轮不把 CI 的 debug 构建当作正式更新包。

仍在使用旧签名的 3.1.2 或更早版本时，先在旧版「我的 → 备份与恢复 → 分享备份」把备份保存到应用之外，确认能找到后，再卸载旧版、安装新版并恢复。详见[签名与迁移说明](RELEASE_SIGNING.md)。

版本码：37。队友特性指宿舍活动解锁的战斗特性；人格面具的剧情觉醒仍由游戏剧情决定。
