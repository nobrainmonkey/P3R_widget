# P3R 规划 3.0.1

在 3.0.0 的基础上，按独立复查的结果补齐剩下的几处：目标的先后顺序、交钱留余、提示文字和外观细节。

## 安排

- **目标严格按顺序优先**：排在前面的目标不会为了后面的目标让步。前面的目标排不到时，会单独为它重新安排一次再比较；某个目标没排到 MAX 时，「社群」页只写真正占用了它时间的那个目标（「先保证了皇帝」），没有把握的原因不写。
- **交钱一定留余**：需要付钱解锁的社群（比如恶魔社群的三次付款），交完钱手上至少还留 2,500 日元；14 天内要交钱时，花钱提升能力和买结缘网站的字条都不会动用这笔钱。只有晚交会赶不上升级目标时，才会留得比这少。
- **「稍后会自动再算一次」只在真的会再算时出现**：自动补算过一次以后，改为「后半段是粗略安排；记下一个结果后会重新安排」。补算出的安排也按目标顺序比较，不会换成一份让前面的目标排不到的安排。

## 界面和用语

- 见面的「怎么做」里，参考回答和「注意：…」显示在步骤下面，用彩色竖线标出，不再算作一步；参考回答不再重复出现两次。
- 文中的日期统一写成「10月23日 周五」；逐日攻略里「主人公」改为官方的「主角」；「结缘网站的字条」始终写全称；路线选「朋友」的社群，卡片上写明「安排不会要求你走恋爱路线」。
- 逐日攻略的小组件和应用里，人名、地点、电视购物的商品名、考试答案和短标签都不会被拆到两行，「（2）」这样的数字也跟着前面的字；字号调大时，较长的括号说明可以正常换行。
- 逐日攻略的文字也按用语表统一：日期写「10月13日」，金额写「3,980 日元」，能力等级写「Lv.2」，「羁绊剧场」改为「羁绊剧情」，去掉了答案后面的英文注释（英语课题目本身的英文选项保留）。条目、编号和打勾进度都不变。
- 「关于」页显示实际安装的版本号。
- README 的截图换成了这一版在模拟器上的实际截图。

## 实测（真实规则包）

- 新游戏、不计人格面具加成：预计 22 个社群全部 MAX；勾选全部羁绊剧情时 21 个。
- 「必须：皇帝」：皇帝 6月29日 MAX，共 21 个 MAX。
- 「必须：皇帝 · 想要：恋爱、女皇」，只给目标社群带人格面具：三个目标都 MAX，共 20 个 MAX。
- 每个场景都排到 1月31日，并通过独立校验。完整表格见 `docs/PLAN_METRICS.md`。

## 安装说明

- 从 3.0.0 直接覆盖安装即可（同一个包名 `app.p3r.planner`、同一个签名证书），记录和设置都会保留，打开后会自动重新安排。
- 从旧版「P3R」（2.0.0）过来：仍然是作为新应用安装，见 README 的说明。
