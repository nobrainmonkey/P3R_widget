# P3R 规划 3.1.2

## 修正

- **救失踪者留出一天余量**：按 Reload 的游戏数据和攻略，期限当天的晚上去塔尔塔罗斯还来得及救出，但这一点没有在游戏里亲自核对过。所以现在只要期限之前还有能去塔尔塔罗斯的晚上，安排就会在期限前一天或更早去救，不再把救人留到期限当天。只剩期限当天能去时（比如进度刚好记到期限那天），安排会照样排上，并写明「按游戏数据和攻略还来得及，但没在游戏里核对过」。
- 失踪者相关的提醒和说明也改成同样的说法。
