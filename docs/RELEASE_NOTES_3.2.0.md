# P3R 规划 3.2.0

## 安装前：签名变更，先备份

本次使用新的正式签名，**不能直接覆盖安装 3.1.2 或此前使用旧签名的 3.x 版本**。包名仍为 `app.p3r.planner`，请按以下顺序迁移：

1. 在旧版打开「我的 → 备份与恢复 → 分享备份」，把目标、设置和全部记录保存到文件或聊天中。
2. **先确认备份已经保存、能够在应用之外找到，不要先卸载旧版。** 确认后再卸载旧版，安装本次新签名的 3.2.0。
3. 在新版打开「我的 → 备份与恢复」，用「选择文件」或「粘贴文字」恢复刚才的备份。

如果还需要旧逐日攻略的打勾进度，卸载前也在同页「旧版逐日攻略 → 导出打勾进度」单独保存一份。新安装的用户可直接安装。签名及私钥备份说明见[发布签名记录](RELEASE_SIGNING.md)。

## 进塔与救援

- 所有失踪者的出现日期和期限都会参与进塔安排，包括没有社群的失踪者。同一期的人还没到齐、而且晚些进塔仍来得及时，会尽量等到一起救，减少来回跑。
- 例如 6月18日、6月26日的两批失踪者，会优先合到 6月26日之后的一次探索里；文吉和舞子的救援也会考虑同一期后来出现的其他人。
- 期限前有可用晚上时，仍留出至少一天余量。剧情占用、次数上限或不同期限使合并不可行时，会分开安排；只剩期限当天时会说明依据尚未在游戏里亲自核对。
- 保留你设置的每区块探索次数和上限。进塔详情会写明这次要一起救几个人。

## 限定菜单

- 定食若津：了解菜单后，魅力达到 Lv.3，可在周一、四、五、日晚上安排水产全席套餐，900 日元、学力 +4。
- 叶隐拉面：了解菜单后，勇气达到 Lv.3，可在周二、三、五晚上安排限定餐，1,200 日元、魅力 +4。
- 会先安排在对应晚上吃普通餐、了解限定菜单，再按三维、日期和现金判断是否选择限定餐。了解菜单本身可以早于三维达标。
- 从中途存档录入时，应用不知道你以前是否了解过菜单，会保守地先安排一次普通餐；详情里会说明。周末怀老鸭套餐仍涉及第 11 号委托完成条件，不会只凭三维就开放。

## 委托提示

- 「今天别错过」中的委托提醒可点开查看做法，包括找谁、去哪里、先交哪一件、多日准备、额外花费和错过风险。
- 补充第 75 号委托的八次教职员室访问提醒，以及第 77–81 号外出邀请的委托完成数量和前次邀请要求。
- 接取、交付委托不消耗时间；第 11 号大胃王挑战会消耗晚上，会在提示里明确区分。
- 委托完成数量、访问次数和委托的额外收支仍由玩家确认；提示中的收益不会自动记入进度。

## 社群对话

- 按已确认的短句预览新增 88 个等级场景、修正 27 个已有场景。女教皇 R3–R7 等原先只显示通用提醒的场景，现在直接给出可辨认的中文选项。
- 小组件继续用「答：A / B」，按提问顺序缩写；详情保留完整顺序、重复回答、「任意」的位置和路线条件。「抱歉（最后一问）」这类定位提示会保留。
- 最小卡片、字体放大到 115% 时，会按需要缩小左右留白，让课堂答案和可能升级的社群回答都能显示。
- 友情与恋人直接按现有社群设置展示，并配套前面的资格选择。中途存档若走过不同分支，详情提供相应问题顺序和答法；不增加一次路线选择。
- 在首轮 115 个场景的基础上，再补全或修正 35 个场景：原来的 8 个空白已补齐，19 个手动社群的 R2–R10 共 171 个等级场景均有提示。教皇 R9、塔 R9、星 R3 经逐项核对确实同分，可任意；恶魔 R10 为观看剧情。
- 优先保留找到的简中选项；缺少中文的部分依据 Reload 的日英资料译意，详情注明「部分选项为译意，按含义对应」。短卡仍用容易辨认的人话关键词，完整问题顺序和译文依据可追溯。
- 千寻友情路线在 R5 保留高收益答法、R9 拒绝告白；谈小说人物的恋爱情感、握手尚未建立恋爱关系。已提前走友情的另一套问题列在详情。
- 本次对话补充不改变好感收益、升级阈值或排程规则。覆盖指有来源的场景提示，不表示已经提取官方全量文本或在游戏内重放所有分支。完整结果见[本轮覆盖记录](analysis/DIALOGUE_COVERAGE_COMPLETED_2026-10-16.md)。
