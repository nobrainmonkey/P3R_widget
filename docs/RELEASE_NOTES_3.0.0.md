# P3R 规划 3.0.0

把「两天推荐」换成真正的整年安排：从你现在的存档一直排到 1 月 31 日，每个白天和晚上都有事做，前后自洽。

## 新功能

- **整年自洽的安排**：每一步对现金、个人能力值、社群 RANK、解锁进度和塔尔塔罗斯次数的影响都会推演下去，后面的安排建立在前面的结果上。手机本地计算，一般 1 秒内完成。
- **先满足目标，再尽量拉满其他社群**：目标分「必须」「想要」，其余社群自动顺带提升。从新游戏开始，不计人格面具加成时预计 21 个社群 MAX，基本都带同阿尔卡那人格面具时 22 个全 MAX（与原中文攻略的路线一致）。
- **白天优先给社群**：能在晚上练的个人能力值不占白天；打工只在需要用钱时安排。
- **多步解锁自动排好**：恶魔的三次付款、正义的三次搭话、倒悬者的送吃的、太阳的红色钢笔、塔和月亮的传闻，都会在合适的日子“顺便”完成。
- **失踪者救援**：北村文吉（9/12–10/3）和舞子（10/21–11/2）会提前留出探索塔尔塔罗斯的晚上。
- **人格面具三档**：不带 / 只给目标社群带 / 基本都带；需要带的那次见面会提醒你带哪个阿尔卡那。
- **结缘网站的字条**：后期把多出来的晚上换成白天社群的好感。
- **羁绊剧情（可选）**：勾选想看的同伴，会在能看的日子留出时段。
- **一下记录结果**：小组件或应用里点「完成」；社群见面只问「升到 RANK 7 了吗？」，塔尔塔罗斯只填最高层和一个现金数字（出塔后余额或这次多了多少，二选一）。
- **偏离了也没关系**：做不了 / 改做别的 / 很久没记录（同步现状），只改和预计不一样的地方，后面自动重新安排；所有记录都能撤销。
- **全新外观**：P3R 风格的深蓝与青色、斜切面板、日历牌日期；桌面小组件昼夜两套配色。

## 安装说明

- 包名改为 `app.p3r.planner`，会作为**新应用**安装，不会覆盖或删除旧版「P3R」（2.0.0）的数据。
- 旧版固定攻略的打勾进度：旧版里导出，新版「我的 → 逐日攻略」里导入。
- 规划进度请用新版的设置向导重新录一次（约 2 分钟）。

## 关于估计

看不见的数值只用保守估计，并和你确认过的进度分开保存。普通见面按 +10 点估计（游戏里约显示 ♪♪），没有官方数据，详见应用内「规划说明」。
